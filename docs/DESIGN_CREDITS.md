# Design approach attribution

ExamFlow's visual refinement applies design principles from **Unslop**, a UI design skill created by Damir Sokolovsky.

- Project: https://github.com/heydamir/unslop
- Author: Damir Sokolovsky — https://heydamir.design/unslop
- License: CC BY 4.0

The implementation in ExamFlow is an independent adaptation of the published design guidance: restrained interface chrome, deliberate spacing, consistent typography, purposeful color, clear data hierarchy, and product-specific details. No Unslop source code or assets are bundled into the application.

Attribution is retained in accordance with the CC BY 4.0 license.
